# Fither to SVG

Give an image or Figma frame a clean, monochrome dither effect, then export it as an SVG. Tweak the threshold, brightness, contrast, and pixel size until it looks right.
Unlike a shader or live effect, Dither to SVG builds the result from squares that stay aligned to the pixel grid. That means clean edges without anti-aliasing on export… as long as you export at the size you intend to use.

## Features

• Apply a monochrome dither to images or Figma frames
• Adjust threshold, brightness, contrast, and pixel size
• Export crisp SVGs with pixel-grid-aligned squares
• Individual square export is optional
• Designed for outputs between 16 x 16 px up to 500 × 500 px
